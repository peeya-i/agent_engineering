# WidgetWare Renewal Discount Policy

Use this reference only for renewal-discount approval routing.

## Approval routing

| Requested discount | Route for approval |
|---|---|
| 0%–10% | Customer Success Manager |
| >10%–15% | Customer Success Director |
| >15%–20% | VP, Customer Success |
| >20% | CRO + Finance review |

## Rules

- A request is **not approved** merely because it falls into a routing band.
- Say `requested` until a routing decision is made.
- Say `routed to <role>` after identifying the approval authority.
- Say `approved` only when explicit approval evidence is present in the task context.
- Never invent approval status.
- If ARR or requested discount percentage is missing, ask for it before performing dollar calculations.
